# Support

Use GitHub Discussions for usage questions and design proposals, and GitHub Issues for reproducible
defects or scoped feature requests. Include environment versions, commands, sanitized logs, and the
smallest reproducible example. This community project does not provide an uptime or response-time
SLA. Never include credentials, private datasets, customer names, or unrestricted logs.

Security and conduct reports use the private channels described in [SECURITY.md](SECURITY.md) and
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
